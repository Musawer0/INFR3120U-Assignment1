Featured Academic & Technical Projects

1. Multi-Region Enterprise MPLS WAN & Phase 3 DMVPN Architecture (INFR 2421U)

Interconnected multi-region campus sites across Toronto, Ottawa, and Oshawa using physical Cisco ISR 4331 enterprise routers and Catalyst switches. Deployed an MPLS core WAN via LDP and engineered a redundant Phase 3 DMVPN backup with IPsec AES-256 encryption.

2. Enterprise Campus Routing & Virtualized Network Architecture (INFR 2411U)

Designed a multi-tier network topology connecting North Oshawa and Downtown Oshawa campus environments over an ISP backbone. Established eBGP and iBGP peering alongside multi-area OSPF, implementing VRF-Lite to isolate internet traffic from private networks.

3. Automated E-Commerce Order Parsing & Cloud Anomaly Monitor

Built automation scripts in Python to parse incoming order event payloads, programmatically identifying fulfillment exceptions and payment delays. Deployed automated monitoring routines on a remote Linux Cloud VPS using scheduled cron jobs.

4. Linux Cloud VPS Server Hardening & Secret Management

Hardened remote Linux cloud host environments by migrating sensitive application API tokens into access-controlled environment files. Configured POSIX permissions, stateful firewall rules, and sanitized logs to protect sensitive operational data.

5. Automated Enterprise Network Diagnostics & TCL Verification

Configured automated TCL diagnostic scripts on Cisco enterprise hardware to verify dynamic routing convergence and failover behaviors. Validated link failover across redundant WAN interfaces and monitored packet behavior using Wireshark captures.
